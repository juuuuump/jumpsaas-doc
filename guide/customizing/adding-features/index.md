# Adding Custom Features

This guide explains how to add your own features to JumpSaaS while keeping them separate from template code. Pick your framework:

- [Next.js](/docs/customizing/adding-features/nextjs) — App Router, server actions, `src/app/[locale]/(app)/`
- [TanStack](/docs/customizing/adding-features/tanstack) — `createServerFn`, `createFileRoute`, `src/routes/{-$locale}/_app/`
